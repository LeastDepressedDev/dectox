# VS code techi
Первое с чего следует начать - как vs code вообще работает с плагинами. Тут довольно классическая ситуация: у нас есть api на js/ts к которому мы обращаемся чтобы вызывать исходные функции среды разработки и базовые операции и данные. Вызов кастомного функционала осуществляется посредством регистрации Ивентов. Есть файл `package.json`, который позволяет ide определить, что перед ней нне просто папка - а плагин. В этом файле содержится информация о том, какие ассеты привносит расширение в VS code.

## Вопрос к реализации
Общая идея работы vscode с плагинами следующая.
`package.json` содержит в себе разные объявления.
Помимо базоывх названия, автор, версия ... есть секция `contribute`. В ней указываются статические элементы, такие как: комманды, кейбинды, гуи.
О них подробнее:
### Комманды
Основная движущая сила расширения. Фактически - комманда - кастомный ивент. Любой такой можно вызвать через Command Palete встроенный в VS code. Объявляются комманды в `contribute`, однако хендлер к ним привязывается при активации расширения.
### Кейбинды
Кейбинд назначается на существующую команду. Вызывает хендлер этой команды по нажатию сочитания клавиш.
### Гуи(Интерфейс)
Пока ещё мало изучен, поэтому от него можно скорее ... чем пользы.
